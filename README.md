# WRONG NUMBER v0.2.1 — LITTLE WINDOW

6キット×16パッドのポケット楽器。GitHub Pages対応。

## 遊び方

- **液晶をタップ**：うさぎと01〜04パッドの16ステップ表示を切り替え。再生中は小節が切り替わります（表示のみ・編集なし）。
- **SOUND KIT**：新しい **BAD SPELLING** は、壊れた音声玩具のような合成母音・子音を鳴らします。音声サンプルや外部APIは使いません。
- **BLANK**：4拍のカウント後、2小節を何周でも録音。DUBで終了。速いBPMなら短押し時は96 BPMで開始、長押しなら現在のBPM。
- **PAD**：タップ演奏、連打で音色変化、長押しでリピート。
- **NEW**：短押しは余白のある伴奏、長押しはフルパターン。
- **LOOP / DUB**：再生・停止／重ね録り。
- **MUTATE / UNDO**：リズムの変異／取り消し。
- **TAPE / WAV**：演奏録音／ループのWAV出力。

## インストール

ZIP内のファイルをGitHubリポジトリのルートへすべて上書きしてください。PWAのキャッシュはv0.2.1へ更新済みです。以前の保存済みループは読み込まれます。

マイク機能はありません。音声は端末内で合成され、外部へ送信されません。iPhone Safari実機は別途確認が必要です。
