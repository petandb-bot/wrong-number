# WRONG NUMBER v0.2.3 — PLAYABILITY REFINEMENT

16パッド／6音源キットのポケット楽器。p5.js（描画）とWeb Audio API（音声）を使用し、GitHub Pagesで公開できます。外部音声の読み込みやマイク入力はありません。

## 使い方

- **PAD**：タップして演奏。連打すると変化し、長押しで短いリピート。
- **BLANK**：4拍後に録音開始。何周でも重ね録りし、DUBで終了。長押しでBPM維持。
- **NEW**：余白のあるビート。長押しすると密度の高いビート。
- **LOOP / DUB**：再生・停止／演奏をループに記録。
- **MUTATE**：リズムを変化。長押しで変化を強める。
- **UNDO**：録音中は直前の打鍵を取り消し、通常は直前の変更を戻す。
- **液晶**：タップでうさぎと01〜04のステップ表示を切替。録音中のステップも確認できます。
- **WAV / TAPE**：ループ書き出し／ライブ演奏の録音。WAV長押しはFX付き4小節。

**BAD SPELLING**は短い単発の合成発声を16種類収録。音声の長い連なりを廃止し、音程の上昇／下降と母音の表情を中心にしました。

## 公開

ZIPの中身をGitHubリポジトリのルートに配置し、**Settings → Pages → Deploy from a branch → main / (root)** を選択してください。従来のセッション保存キーは維持しています。PWAのキャッシュはv0.2.3です。

## 技術上の注意

- 音声エンジンはWeb Audio API。WAVは44.1 kHz・16-bit・ステレオで出力します。
- UNDO履歴（最大8件）をブラウザのlocalStorageに保持します。ブラウザのデータを消去した場合は復元できません。
- 偶発FXは現在、短い合成音を追加する方式です。再生中のマスター音声を直接切断・逆再生しているわけではありません。
- iPhone Safari実機の音声処理・保存操作は未検証です。Chromiumでのタッチ操作模擬と音声レンダリングを検証しています。
