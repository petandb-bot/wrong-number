# WRONG NUMBER v0.1.0

**A small instrument that remembers your mistakes.**

ゲームボーイ／電卓型の16パッドを備えた、ブラウザ用の小さな生成楽器です。
p5.js 1.11.13で液晶表示を描画し、音はWeb Audio APIで合成します。
外部サウンド素材やサーバーは必要ありません。16パッドはすべてコードで生成する音色です。

## 含まれるもの

- `index.html` — UI構造と遊び方
- `style.css` — レトロな携帯楽器風のスマホ向けデザイン
- `app.js` — 演奏、2小節シーケンサー、MUTATE、KEEP、画面表示、WAV出力
- `audio.js` — 独自の16音色、空間系エフェクト、WAVエンコーダー
- `manifest.webmanifest` / `sw.js` — ホーム画面登録・オフラインキャッシュ
- `assets/` — アプリアイコン
- `tests/smoke.py` — Chromium / Playwrightの操作・WAV出力スモークテスト

## 操作

1. 最初に好きなパッドをタップして、音声を有効化します。
2. 1回押すと発音します。連打すると音色が変わり、約0.37秒以上長押しすると音を細かく反復します。
3. `LOOP` を押すと、直前の演奏を2小節（32ステップ）に量子化して再生します。何も演奏していなければ生成パターンを使います。再生中にタップした音は次周以降のパターンに追加されます。もう一度 `LOOP` を押すと停止します。
4. `MUTATE` はパターンの配置・音色・響きを部分的に変異させます。約0.65秒以上押すと強めに変異します。
5. `KEEP` で現状を記憶し、`RESTORE` で記憶した状態に戻ります。`NEW` は新規パターンを作成します。
6. `MAKE WAV` でパターンをオフライン合成し、表示される `DOWNLOAD WAV` を押して保存します。iPhoneのファイル共有に対応する環境では `SHARE / SAVE TO FILES` も表示します。
7. `−` / `＋` でテンポを2BPMずつ変更できます（48–180BPM）。

PCキーボード: `1 2 3 4` / `Q W E R` / `A S D F` / `Z X C V`。

## GitHub Pagesで公開する

1. GitHubで **新しい公開リポジトリ**（例：`wrong-number`）を作成します。
2. ZIPを展開し、`index.html`・`audio.js`・`app.js`・`style.css`・`sw.js`・`manifest.webmanifest` と `assets` フォルダを **リポジトリ直下** にアップロードします。`wrong-number-v0.1` というフォルダを丸ごと一段下に配置しないようにしてください。
3. リポジトリの `Settings` → `Pages` → `Build and deployment` で `Deploy from a branch` を選び、`main` / `/(root)` を指定して保存します。
4. 公開完了後、URL `https://<GitHubユーザー名>.github.io/wrong-number/` から開けます。正確なURLはGitHub Pages画面に表示されます。
5. iPhone Safariで開き、**共有 → ホーム画面に追加**。表示される場合は「Webアプリとして開く」を選びます。以降はホーム画面から起動します。

ローカルの動作確認は、展開したフォルダ内で `python -m http.server 8000` を実行し、`http://localhost:8000` にアクセスします。macOS／Windowsとも実行可能です。

## 設計・音響仕様

- 16内蔵音源は `OscillatorNode`、`BufferSourceNode`、FM変調、フィルターなどの組み合わせ。外部音声ファイルは未使用。
- ライブのシーケンスは25ms間隔、140ms先読みでスケジューリング。16分音符単位の記録・再生、2小節固定。
- リバーブとテンポ非同期ディレイ、コンプレッサーを内蔵。
- WAVは **44,100Hz / 16-bit PCM / stereo**。同一の音源スケジューリング関数でオフライン3周分をレンダリングし、中央の1周を抜き出すことで前周からの残響を維持します。ピーク調整は最大2.3倍まで。
- セッションとKEEPスナップショットはブラウザの `localStorage` に保存。サイトデータの削除などで消えるため恒久保存ではありません。
- p5.js 1.11.13 は公式jsDelivr CDNから読み込み。読み込めない／オフラインの場合でも、ローカルCanvas描画に自動切替して演奏と表示を継続します。最初にオンラインで開く必要があるのは、主にページ資産をService Workerがキャッシュするためです。

## v0.1の範囲外

- マイク録音・外部音声ファイル読み込み（v0.2で実装予定）
- 8小節や任意小節数のシーケンサー
- 演奏全体の独立したライブ録音（v0.1はループ書き出しのみ）
- MIDIコントローラー、オーディオインターフェースの詳細設定
- iPhone実機での音質・バッテリー・PWAの安定性検証

## 注意点

- iOS Safariでは音声開始にユーザーのタップが必要です。画面ロック・バックグラウンド再開後に再生できなくなるiOS／WebKit由来の問題が報告されています。その際はページを再読み込みし、パッドから再開してください。
- WAVを生成した後、**ダウンロードまたは共有ボタンを押して**保存してください。自動で端末の音楽ライブラリには入りません。
- 長時間の複数指押し・重いWAV合成についてはiPhone実機での負荷確認が必要です。
- 端末内の音量を小さめにして初回再生してください。

## テスト

`tests/smoke.py` はPlaywrightとChromiumを利用します。`python tests/smoke.py` で演奏・ループ・MUTATE・KEEP・RESTORE・テンポ変更・WAVヘッダー（ステレオ44.1kHz 16-bit）を検証できます。

このプロジェクトは実験的な音楽ソフトウェアの初期プロトタイプです。v0.1は音源の個性とパターン変異の評価を目的にしています。
