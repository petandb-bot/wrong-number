# WRONG NUMBER v0.2.0 — PLAY WITH IT

5キット×16パッドの、小さく奇妙なポケット楽器。GitHub Pagesで公開できます。

## 遊び方

- **BLANK**：4拍のカウント後に録音開始。2小節を何周でも重ね録りできます。DUBで終了。
- **BPM**：速い状態（111以上）でBLANKを短押しすると96 BPMから開始。BLANK長押しは現在のBPMで開始。
- **PAD**：タップで演奏、連打で音色に変化、長押しでリピート。
- **NEW**：短押しは余白のあるループ、長押しは音数の多いループ。JAM中は短い演奏に小さな返事が時々鳴ります（録音パターンには加わりません）。
- **LOOP / DUB**：再生・停止／演奏の重ね録り。
- **MUTATE / UNDO**：パターンを変化／取り消し。
- **TAPE / WAV**：演奏を録る／ループを書き出す。

うさぎは全身のまま、3匹のダンス、転び、光る足元や星のアクシデントを表示します。
