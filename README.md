# WRONG NUMBER v0.1.9 — BLANK BEAT

iPhoneで演奏できる、5キット×16パッドのポケット楽器です。今回から空のパターンを作れます。

## 使い方

- **BLANK**：空の2小節ループを開始。DUBが自動でONになり、叩いた音を記録します。
- **DUB**：もう一度押すと記録終了。再び押せば続きを追加できます。
- **NEW**：短押しで余白のあるループ、長押しで音数の多いループ。押すとボタンが一瞬だけ変色します。
- **LOOP**：再生・停止。従来の操作は変更していません。
- **MUTATE**：ループを変化。長押しで大きく変化。
- **UNDO**：直前のNEW、BLANK、DUB、MUTATEを取り消します。
- **TAPE / WAV**：演奏全体の録音／2小節の書き出し。

音色とKIT切替は従来どおりです。画面上部では3匹のうさぎが演奏に合わせて踊ります。

既存の保存済みパターンは引き継ぎます。以前のKEEP用データは削除しませんが、今回の操作画面では使いません。更新後、以前の画面が残る場合はSafariの再読み込み後、ホーム画面アプリを終了して起動し直してください。
