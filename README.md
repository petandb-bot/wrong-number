# WRONG NUMBER v0.2.2 — HAPPY ACCIDENTS

6キット×16パッドのWeb楽器。GitHub Pagesで動作します。

## 遊び方

- **BLANK**：4拍カウントして空の2小節を録音。何周でも重ね録りでき、DUBで終了。
- **NEW**：余白のあるビートを生成。長押しは音数の多いビート。
- **PAD / LOOP / DUB**：叩く、繰り返す、重ね録りする。
- **MUTATE / UNDO**：構造を変える／戻す。
- **液晶**：タップすると01〜04パッドのシーケンスを表示。再タップでうさぎに戻ります。
- **BAD SPELLING**：多音節・フォルマント変化を使った、改造音声玩具風の音源に刷新。
- **HAPPY ACCIDENTS**：4小節に1回ほど、STUTTER / REVERSE / TAPE BEND / CRUSH の短いエフェクトが発生。DUB中は発生しません。
- **TAPE**：演奏中の音と偶発FXを録音（最大30秒）。
- **WAV**：短押しで通常の2小節ループ。**長押しでFXを含む4小節**（最後の2小節にエフェクト）を書き出します。

## GitHub Pages

ZIPを解凍し、中の全ファイルをリポジトリのルートに配置します。
Settings → Pagesで main / (root) を公開してください。

従来のセッション保存データは引き継ぎます。マイク入力はありません。

## 実装上の注意

- 音声はWeb Audio APIによる合成音です。音声ファイルの配布やAI音声合成ではありません。
- REVERSEは元のパッド音そのものの逆再生ではなく、合成した短い音響片を逆再生構造で鳴らすものです。
- FXは通常のループパターンには書き込まれません。WAV短押しはクリーンな2小節、WAV長押しとTAPEにはFXが反映されます。
- iPhone Safari実機の再生・ファイル保存は別途確認が必要です。
