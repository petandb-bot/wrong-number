# WRONG NUMBER v0.2.4 — REAL ACCIDENTS

16パッド・6キットのポケット楽器。GitHub Pages向け静的Webアプリです。

## 使い方

- **PAD**：タップで演奏。連打・長押しで音が変化。
- **BLANK**：4拍カウント後、何周でも録音。DUBで終了。長押しはBPM維持。
- **NEW**：余白のあるビートを生成。長押しで密度の高いビート。
- **LOOP / DUB**：再生・停止／重ね録り。
- **MUTATE / UNDO**：リズムを変異／直前の変更を戻す。
- **液晶タップ**：うさぎと01～04のステップ表示を切替。
- **液晶長押し**：偶発FXの頻度を **SOFT → WILD → OFF** の順に切替。起動時はSOFT。
- **TAPE / WAV**：演奏を録音／クリーンな2小節を書き出し。WAV長押しはFX入り4小節を書き出し。

## v0.2.4の音響変更

STUTTER、REVERSE、TAPE BEND、CRUSHは、発動するパッドの音を事前に短くレンダリングし、そのPCMを加工します。該当する発音をFX版に**置き換える**ため、元の音に装飾音を重ねません。低域の土台を優先し、主として05～16番の音が対象です。

- **STUTTER**：実際のパッド音の短い断片を反復。
- **REVERSE**：実際のパッド音の断片を逆再生。
- **TAPE BEND**：実際のパッド音の速度・音程を下降。
- **CRUSH**：PCMの量子化と間引き。

SOFTは約4小節に1回、WILDは約2小節に1回を上限として、該当する音が存在する箇所だけ発動します。DUBの録音中、カウントイン中は発動しません。事前レンダリングが間に合わない場合は通常音を鳴らします。WAV長押しは、画面のFX設定とは独立してFX版を書き出します。

これはパッド単位のワンショット加工であり、マスター出力全体を録音・切断するEffectrix型の全帯域ループ処理ではありません。

## 公開方法

ZIPを展開し、ファイル一式をGitHubリポジトリのルートへ配置します。**Settings → Pages → Deploy from a branch → main / (root)** を設定してください。既存のセッション・UNDO履歴の保存キーは維持しています。

## 技術・検証

- p5.js（表示・利用可能な場合）とCanvasフォールバック。音声はWeb Audio API。
- PCMバッファの事前レンダリングには `OfflineAudioContext` を使用。FX素材は最大10件キャッシュ。
- 44.1kHz・16-bit・ステレオWAVを書き出し。TAPEは最大30秒。
- JavaScript構文、同梱テスト、Chromiumによる4 FXのオフライン音声実測とFX付きWAV出力を確認。
- iPhone Safariの実機における長時間演奏・音量バランスは未検証。

ローカルのテストは `node tests/test-audio.cjs` および `node tests/test-app.cjs`。
