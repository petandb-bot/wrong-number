# WRONG NUMBER v0.1.8.1 — PLAYABLE SPACE

16パッドと5つの音源キットを使った、スマートフォン向けの小さな電子楽器です。v0.1.8から演奏機能は変更していません。

## 遊び方

1. **NEW** を押してビートを作り、**LOOP** で再生します。
2. パッドを叩いて演奏します。長押しは連打。普通に叩くだけならループは変わりません。
3. **DUB** を押すと演奏をループへ記録。もう一度押すと終了します。
4. **MUTATE** で変化させ、気に入ったら **KEEP**。**RESTORE** で戻せます。
5. **TAPE** で演奏を録音、**WAV** で現在のループを書き出します。

**NEW長押し**では音数の多いループを作れます。音源キットとBPMは上部で変更できます。
